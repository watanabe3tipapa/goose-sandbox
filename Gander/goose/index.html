Language corner / Goose

Gooseno heap / no GC / no lifetimes

Goose は、ヒープアロケータもガベージコレクタもライフタイム注釈も持たないシステムプログラミング言語です。 値はデータスタックにインラインで置かれ、スコープの終了がそのまま解放になります。 ここでは 8 つの特色を、実際のコード片と小さなモデルで読みます。

02 — DATA STACK MODEL

解放を目で見る

Goose のデータスタックを単純化したモデルです。スコープに入り、バイトを積み、スコープを抜けると、内側の領域が 1 回の巻き戻しで解放されることを確認できます。
