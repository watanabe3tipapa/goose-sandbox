03 — LANGUAGE CORNER

Goose 言語コーナー

アトラスの土台にある Goose という言語そのものを読むコーナー。ヒープなし・GCなし・ライフタイム注釈なしの設計を、8 つの特色とデータスタックのモデルで確かめます。

8 features

メモリモデルからスレッドまで

データスタック、成長しても無効化されない参照、ルート推論、インライン配置、可変モードの ADT、相対参照、共有メモリなしのスレッド、階層を越える return。Goose の特色をコード片と一緒に並べています。

no heap no GC no lifetimes data stack
Goose コーナーを開く 言語ガイド
data stack 
for round in 3 {
    var scratch: u8[>..] = [];
    for i in 100000 { scratch.push((i % 256) as! u8); }
    print("round ", round, ": ", scratch.len, " bytes");
}   // スコープ終了で 1 ストアで解放

成長はポインタの前進、解放はスコープ終了時の巻き戻し。個別の free もデストラクタもありません。

04 — LAB

KeyLint Lab

アトラスの 07 は、読むだけでなく試せる実験台です。ダミーの秘密を入れて、7 段階のどこで止まるかを観察できます。

Interactive

判定の途中を見せる

Pattern → Context → Entropy → Allowlist → Mask → Risk → Baseline の順に通過・停止を並べます。結果だけではなく、なぜその判定になったかを読むための Lab です。
