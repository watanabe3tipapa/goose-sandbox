データについて

    
文書はこのブラウザの localStorage にのみ保存されます。書き出し（Markdown / HTML / JSON / Quarto / Plain Text）はすべて端末内で生成されます。

    
Rich と Source は同じ文書の別の面です。どちらで編集しても、もう一方へ即時に反映されます。
